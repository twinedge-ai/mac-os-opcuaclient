# Security Policy

## Reporting Vulnerabilities

Please report security issues privately before opening a public issue. Use
GitHub private vulnerability reporting if it is enabled for the repository, or
contact the maintainer through the repository owner profile.

Include:

- affected version or commit
- reproduction steps
- expected and actual behavior
- impact assessment

## Supported Versions

Security fixes target the current `main` branch until tagged releases are
published.

## Notes

This app can connect to industrial OPC UA systems. Test changes against local or
non-production servers first. Do not attach real production endpoints,
credentials, certificates, or exported configurations to public issues.
